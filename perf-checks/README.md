# Router performance checks

These projects measure TypeScript type-check time (`vue-tsc`) and Vite build time for different router setups.

All four projects are copies of the same app: a console with 50 lazy-loaded pages. Only the router setup is different.

| Folder                | Router setup                                                    |
| --------------------- | --------------------------------------------------------------- |
| `classic`             | `createRouter()` with a hand-written `RouteRecordRaw[]`         |
| `auto-routes`         | `createRouter()` with `vue-router/auto-routes`                  |
| `auto-resolver`       | `experimental_createRouter()` with `vue-router/auto-resolver`   |
| `auto-resolver-props` | `auto-resolver` plus `definePage({ props: true })` on each page |

Results: [REPORT.md](./REPORT.md).

## Files that matter

- `src/router.ts`: the router setup. This file is different in each project.
- `vite.config.ts`: `classic` has only the Vue plugin. The other projects also have the `vue-router/vite` plugin.
- `tsconfig.app.json`: the generated projects add the two `vue-router/volar` plugins.
- `src/routes.d.ts`: generated by the Vite plugin. It is not in git.
- `setup.mjs`, `measure.mjs`, `smoke.mjs`: the scripts.

## Keep in sync

When you change one project, apply the same change to all projects:

- All of `src/` except `router.ts` and `routes.d.ts` must be byte-identical. `measure.mjs` checks this and stops if a file is different.
- `auto-resolver-props` pages have exactly one more line: `definePage({ props: true })`.
- `index.html`, `tsconfig.node.json`, and `package.json` (except `name`) are identical.
- `tsconfig.app.json` and `vite.config.ts` are identical in the three generated projects.

## Run

First, install the dependencies and build the router from the repository root:

```sh
pnpm install
pnpm --filter vue-router run build
node perf-checks/setup.mjs # links each project's node_modules to the file-based playground
```

Then pick a flavor:

```sh
# Quick: classic only, 3 runs
node perf-checks/measure.mjs

# One or more projects
node perf-checks/measure.mjs auto-routes auto-resolver --runs 3

# All projects
node perf-checks/measure.mjs --all --runs 5

# All projects with TypeScript traces (in results/<project>/trace-app)
node perf-checks/measure.mjs --all --runs 5 --trace

# Browser checks of the builds (needs agent-browser). Run measure first.
node perf-checks/smoke.mjs
node perf-checks/smoke.mjs classic

# Open one build in the browser
cd perf-checks/classic && node node_modules/vite/bin/vite.js preview
```

Output goes to `results/` (not in git):

- `summary.json`: timings, compiler stats, bundle sizes.
- `<project>/*.log`: full command output.
- `smoke.json`: browser check results.

`smoke.mjs` exits with code 1 if the `auto-resolver-props` build does not pass the route params as props.
